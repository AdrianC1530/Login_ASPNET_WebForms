# Login con ASP.NET Web Forms

Práctica de una pantalla de **inicio de sesión** con **ASP.NET Web Forms** en C#.

## Archivos principales

- `WebApplication1/login.aspx`: formulario de ingreso.
- `WebApplication1/login.aspx.cs`: lógica de validación.

## Cómo ejecutarlo

Abrir `WebApplication1.sln` en Visual Studio y ejecutar con F5 (IIS Express).

## Tecnologías

C#, ASP.NET Web Forms, .NET Framework.
